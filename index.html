Nav2 日本語ガイド

ROS 2 でロボットを目的地まで動かすソフトウェア群 Nav2 を、実際に動かしながら学ぶ。

このサイトは作成中

  • まだ読者の案内はしていない。ページの中身は、予告なく書き直すことがある。
  • 読む順番の表で「準備中」としたページは、まだ無い。

Nav2 は、ROS 2 の上で動く、ロボットの移動のためのソフトウェア群である。地図の上で自分の位置を推定し、障害物を避ける経路を考え、その経路に沿ってロボットを動かす。このサイトは、Nav2 の公式の文書（docs.nav2.org の Jazzy 版）を基に、学ぶ順番に並べ直し、日本語で説明し直したものである。逐語の翻訳ではない。

読者として、Nav2 を自分たちの製品に組み込もうとしている開発者を考えている。Python と C++ の文法と、Linux の基本的なコマンドを知っていれば読める。ROS 2・Nav2・Gazebo（ロボットのシミュレーター）は知らなくてよい。ROS 2 の考え方は、理論から入らず、手を動かす場面で要る分だけ、その場で説明する。

前提の版は ROS 2 Jazzy と、Nav2 の Jazzy 版である。シミュレーターは Gazebo Harmonic を使う。PC は Windows 11 に WSL2 で Ubuntu 24.04 を入れた形を主にし、Ubuntu を直接入れた PC でも読めるようにしている。

ページの読み方

コマンドの箱

コマンドの箱には、実行するコマンドだけを書いている。箱の 1 行めの # T1 は、「1 つめのターミナルで実行する」という印である。# から後はコメントなので、打たなくてよい。2 つめのターミナルを開いて実行するものは # T2 で表す。コマンドとコマンドの間の空行は、区切りを見やすくするためのもので、1 行ずつ順に実行する。

次は、環境構築の 7 節の例である。T1 でサンプルの node（ROS 2 のプログラムの単位）を動かしたまま、新しいターミナルを開き、T2 で別の node を動かす。

# T1
source /opt/ros/jazzy/setup.bash

ros2 run demo_nodes_cpp talker
# T2
source /opt/ros/jazzy/setup.bash

ros2 run demo_nodes_py listener

期待する結果

コマンドを実行する手順の直後には、「期待する結果」の箱を置いている。箱の中には、画面に出る表示の例と、その読み方を書く。上の例では、次のようになる（表示は一部を抜き出した）。

期待する結果

T1（talker）:

[INFO] [1795261363.550229313] [talker]: Publishing: 'Hello World: 3'
[INFO] [1795261364.550583601] [talker]: Publishing: 'Hello World: 4'

T2（listener）:

[INFO] [1795261364.568141991] [listener]: I heard: [Hello World: 4]
[INFO] [1795261365.552197188] [listener]: I heard: [Hello World: 5]

talker の Publishing の番号と、listener の I heard の番号が対応していれば、やり取りできている。

灰色の箱が表示の例、その後の文が読み方である。この例の詳しい読み方は、環境構築の 7 節にある。

表示の例には、ページを作成したときの環境で実際に出たものと、ソースと公式の説明から想定したものがある。実際に出たものも、画面（Gazebo や RViz）を出して確かめたか、画面を出さずに確かめたかに分かれる。どれに当たるかは、各ページの冒頭の「このページについて」の注記に書いている。

時刻（角括弧の中の長い数字）・プロセスの番号・パスなど、実行するたびに変わる部分は、各ページでその旨を書いている。自分の表示が例と違うときは、読み方の説明を見て、どこが違うのかを比べる。
